# ליגת המילים ⚽

משחק כדורגל ללימוד אוצר מילים באנגלית (אנגלית → עברית), לשחקן יחיד, בדפדפן. עובד בטלפון ובמחשב, בלי התקנה ובלי הרשמה.

*A football-themed vocabulary game for Hebrew speakers learning English. Single HTML file, no dependencies.*

## איך משחקים

- מופיעה מילה באנגלית והיא מוקראת בקול. בוחרים את התרגום הנכון מתוך ארבע תשובות.
- תשובה נכונה היא מסירה קדימה. אחרי שתי מסירות בועטים לשער, והתשובות מחכות בתוך השער.
- טעות: היריבה חוטפת את הכדור. תשובה נכונה מחזירה אותו, טעות נוספת היא גול נגדך.
- ציור של המילה מתגלה רק אחרי שעונים, כדי שלא יסגיר את התשובה.
- מילה שטעו בה חוזרת שוב בהמשך המשחק.

## מבנה המשחק

שני חלקים של מילים, לכל אחד עונה של חמישה מחזורים ואלבום קלפים:

| חלק | מילים |
|---|---|
| חלק 1 | 40 מילים |
| חלק 2 (עמוד 27) | 45 מילים |

הקושי עולה ממחזור למחזור:

| מחזור | מה משתנה |
|---|---|
| 1 | המילים הקלות, בלי שעון |
| 2 | מילים חדשות, התשובות השגויות מאותו חלק דיבר |
| 3 | המילים הקשות, 15 שניות לתשובה |
| 4 | כל המילים, 12 שניות, בבעיטה רק שומעים את המילה |
| 5 | הגמר: שמיעה גם בהגנה, 10 שניות |

צריך ניצחון כדי לעלות למחזור הבא. ההתקדמות נשמרת בדפדפן של השחקן (`localStorage`).

## הרצה

פותחים את `index.html` בדפדפן. זה הכול.

אפשר גם לארח את המאגר ב-GitHub Pages (Settings → Pages → Deploy from branch → `main`), ואז המשחק זמין בקישור.

## מבנה הקבצים

```
index.html            המשחק המוכן, קובץ עצמאי (נבנה אוטומטית)
src/word-league.html  קוד המקור: עיצוב, מילים ולוגיקה
build.sh              בונה את index.html מתוך src
```

עורכים רק את `src/word-league.html`, ואז מריצים:

```bash
bash build.sh
```

## הוספה או שינוי של מילים

המילים נמצאות במערך `W` בתוך `src/word-league.html`. כל שורה היא מילה אחת:

```js
['calendar', 'לוח שנה', '📅', 'n', 1],
// אנגלית, עברית, ציור (אימוג'י), חלק דיבר (n / v / adj / ph), רמת קושי (1 עד 3)
```

אפשר להוסיף אובייקט שישי עם `say` (טקסט להקראה אם שונה מהכתיב), `tag` (למשל `v` כדי להציג "(v)") או `grp` (מילים עם אותו `grp` לא יופיעו כתשובות שגויות זו של זו).

## טכנולוגיה

HTML, CSS ו-JavaScript בלי ספריות. ההקראה משתמשת ב-Web Speech API של הדפדפן, והצלילים נוצרים ב-Web Audio.
